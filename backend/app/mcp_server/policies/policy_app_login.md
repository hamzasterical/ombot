# App or login issue

> Sample bank policy. Synthetic content for demonstration only; not real regulation.

## Common causes
- Outdated app version
- Expired session or biometric reset
- Network problems
- Device incompatibility

## Standard checks
- Confirm app version and device
- Check for known incidents
- Check that the account is not locked for security reasons

## Standard response
Share basic troubleshooting: update the app, restart the device, reset the password through the official flow. Never ask for the PIN or OTP.
